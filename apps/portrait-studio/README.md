# Portrait Studio

リアルな人物画像を生成するためのUI。OpenAI（ChatGPT）の Images API を利用します。

ビルド不要の静的アプリ（HTML / CSS / JS のみ）＋ 依存ゼロの Node プロキシで構成しています。

---

## できること

| 機能 | 内容 |
|------|------|
| プロンプト入力 | 基本プロンプト・避けたい要素・リアリティ指示の自動付与 |
| 人物・撮影設定 | 年齢層／性別表現／体型／髪型／表情／ポーズ／背景／ライティング／レンズ／仕上がり（候補付きの自由入力） |
| 服装指定 | 自由記述の服装プロンプト＋部位別入力（トップス・ボトムス・アウター・靴・小物・色/素材）＋プリセット保存 |
| 情報資料 | 画像・テキストをブラウザに保存し、チェックで選択して生成に使用 |
| 生成 | サイズ・品質・枚数・出力形式を指定して生成、結果のダウンロード／資料への再登録 |

### 情報資料の扱い

- **画像を選択している場合** → `POST /v1/images/edits` に参照画像として添付（複数可）
- **画像を選択していない場合** → `POST /v1/images/generations` を使用
- **テキスト資料** → プロンプトの「【参考資料】」セクションに本文が追記されます

資料は IndexedDB（画像・テキスト本体）、入力内容・服装プリセット・選択状態は localStorage に保存されます。すべてブラウザ内に閉じており、サーバーには送信されません。

## 起動方法

### 1. プロキシ経由（推奨）

APIキーがブラウザに入らないため、共有端末でも扱いやすい構成です。Node 18 以上が必要です。

```bash
cd apps/portrait-studio
OPENAI_API_KEY=sk-... node server.mjs
# → http://localhost:5173
```

UIの「接続設定」で **接続方法＝プロキシ経由**、**ベースURL＝`/api`** のままにします。

環境変数:

| 変数 | 既定値 | 説明 |
|------|--------|------|
| `OPENAI_API_KEY` | （必須） | OpenAI APIキー |
| `PORT` | `5173` | 待ち受けポート |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | 上流エンドポイント |

プロキシが中継するのは `/images/generations` と `/images/edits` のみです。リクエストボディは変更せず、`Authorization` ヘッダーだけを付与して転送します。

### 2. ブラウザから直接

`index.html` をブラウザで開き、「接続設定」で **接続方法＝ブラウザから直接** を選んでAPIキーを入力します。

APIキーはその端末の localStorage に保存されます。個人の端末でのみ使用してください（ブラウザから直接呼ぶ場合、開発者ツールからキーが参照できます）。

---

## モデル

既定は `gpt-image-1` です。接続設定のモデル欄で変更できます（`gpt-image-1-mini` など）。

送信されるパラメータ: `model` / `prompt` / `n` / `size` / `quality` / `output_format`、参照画像がある場合は `image[]`。

---

## ファイル構成

```text
apps/portrait-studio/
├── index.html   # 画面
├── styles.css   # スタイル（ライト／ダーク自動切替）
├── app.js       # プロンプト合成・資料ライブラリ・API呼び出し
└── server.mjs   # 静的配信＋OpenAI APIプロキシ（依存なし）
```

---

## 利用上の注意

- 実在する人物に似せた画像の生成や、本人の同意がない写真を資料としてアップロードすることは避けてください。
- 生成した画像を公開・配布する場合は、AIによる生成物である旨を明示してください。
- OpenAI の利用規約およびコンテンツポリシーに従って利用してください。
