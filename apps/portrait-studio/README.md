# Portrait Studio

リアルな人物画像を生成するためのUI。プロンプトと参考資料を組み立てて、**ChatGPTの画面に貼り付けて生成**します。APIキーは不要です。

ビルド不要の静的アプリ（HTML / CSS / JS のみ）。`index.html` をブラウザで開くだけで動きます。

---

## 使い方

1. `index.html` をブラウザで開く。
2. 左の「情報資料」に、参考にしたい画像やテキストをドロップして保存する（保存されるので、次回以降はチェックを入れるだけで選べます）。
3. 中央でプロンプト・人物設定・服装を入力する。
4. 右の「生成用プロンプト」が自動で組み上がるので、**「プロンプトをコピー」**を押す。
5. 参考画像を使う場合は「参考画像を書き出す」でダウンロードし、ChatGPTの入力欄に添付する。
6. ChatGPTに貼り付けて送信する。
7. できあがった画像は、この画面の資料エリアにドロップすれば次回の参考資料として保存できます。

「ChatGPTを開く」ボタンから `chatgpt.com` を別タブで開けます。

---

## できること

| 機能 | 内容 |
|------|------|
| プロンプト入力 | 基本プロンプト・避けたい要素・リアリティ指示の自動付与 |
| 人物・撮影設定 | 年齢層／性別表現／体型／髪型／表情／ポーズ／背景／ライティング／レンズ／仕上がり（候補付きの自由入力） |
| 服装指定 | 自由記述の服装プロンプト＋部位別入力（トップス・ボトムス・アウター・靴・小物・色/素材）＋プリセット保存 |
| 情報資料 | 画像・テキストをブラウザに保存し、検索・チェックで選択して利用 |
| 出力 | 画角とバリエーション数を指定し、プロンプトをコピー／参考画像を書き出し |

### データの保存場所

- 資料の画像・テキスト本体 → **IndexedDB**
- 入力内容・服装プリセット・選択状態 → **localStorage**

すべてブラウザ内に保存され、どこにも送信されません。別の端末やブラウザには引き継がれない点に注意してください。

## ファイル構成

```text
apps/portrait-studio/
├── index.html   # 画面
├── styles.css   # スタイル（ライト／ダーク自動切替）
├── app.js       # プロンプト合成・資料ライブラリ・コピー／書き出し
└── server.mjs   # ローカル配信＋OpenAI APIプロキシ（API直接生成モードを使う場合のみ）
```

`index.html` を直接開く方法で問題ありませんが、ローカルサーバー経由で開きたい場合は以下でも起動できます（APIキー不要）。

```bash
cd apps/portrait-studio
node server.mjs   # → http://localhost:5173
```

## （任意）APIで直接生成するモード

ChatGPTの画面を経由せず、OpenAI の Images API から直接生成することもできます。使う場合のみ「設定」→ 使い方を **APIで直接生成する** に切り替えてください。

- 参考画像を選択している場合 → `POST /v1/images/edits` に参照画像として添付
- 参考画像を選択していない場合 → `POST /v1/images/generations`
- 既定モデルは `gpt-image-1`

APIキーをブラウザに保存したくない場合は、同梱のプロキシを使います。

```bash
OPENAI_API_KEY=sk-... node server.mjs
```

| 変数 | 既定値 | 説明 |
|------|--------|------|
| `OPENAI_API_KEY` | （必須） | OpenAI APIキー |
| `PORT` | `5173` | 待ち受けポート |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | 上流エンドポイント |

プロキシが中継するのは `/images/generations` と `/images/edits` のみで、リクエストボディは変更せず `Authorization` ヘッダーだけを付与して転送します。

## 利用上の注意

- 実在する人物に似せた画像の生成や、本人の同意がない写真を資料としてアップロードすることは避けてください。
- 生成した画像を公開・配布する場合は、AIによる生成物である旨を明示してください。
- OpenAI の利用規約およびコンテンツポリシーに従って利用してください。
