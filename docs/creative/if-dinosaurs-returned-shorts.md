## 0. コアコンセプト（ここが企画の心臓）

この動画の最大の武器は、**「恐竜が街を壊す映像」を見せないこと**である。

怪獣映画の構図（破壊 → パニック → 軍が倒す）を採用した瞬間、視聴者の脳は「フィクション」と判定し、スクロールする。
本作は逆を行く。**科学的に正しい結末＝「大型種はほとんど自滅する」** を軸に据える。

現実に恐竜が現代へ戻された場合、彼らを殺すのは兵器ではない。

| 殺すもの | 理由 |
|---|---|
| **現代の病原体** | 中生代の免疫系は、6600万年分進化した細菌・真菌・ウイルスに対する獲得免疫を持たない |
| **腸内細菌叢の欠如** | 消化を支える共生菌が失われている。植物食恐竜は「食べても栄養にならない」 |
| **食性の不一致** | イネ科草本（シリカを含む）や現代被子植物は、彼らの歯・消化系の想定外 |
| **熱環境** | 巨大恒温／中温動物にとって、都市のヒートアイランドと日本の高湿度は放熱の地獄。逆に冬は致命的 |
| **騒音・振動ストレス** | 慢性的な過剰刺激による摂食障害・免疫低下 |

そして生き残るのは、**小型・羽毛を持つ獣脚類**だけ。
体が小さく、代謝が速く、雑食で、都市の隙間に営巣できるもの。つまり **「カラスと同じ生き方ができる者」** だけが残る。

**この動画の結末は「破壊」ではなく「置換」である。**
世界は終わらない。生態系の一段が、静かに書き換えられる。

これがドキュメンタリーとして最も怖く、最もリアルで、最後まで見られる構成になる。

### 2-3. 恐竜の「正しい」描写ルール（CG感を消す最重要項目）

**間違った恐竜像＝一瞬でフィクションに見える。** 以下を厳守。

| ルール | 内容 |
|---|---|
| **羽毛** | 小〜中型獣脚類（ドロマエオサウルス類）には必ず羽毛。ウロコ剥き出しの「ラプター」は禁止 |
| **手首の向き** | 手のひらは**内向き**（拍手する向き）。手の甲が下を向く「ゾンビハンド」は禁止 |
| **尾** | 地面に引きずらない。脊椎と水平に保持 |
| **口** | 常時歯を剥き出しにしない。多くは唇状組織で歯が覆われる |
| **咆哮** | **吠えない。** 鳥類・ワニ類に近い、低周波のうなり・シューという呼気音・くちばしを打ち鳴らすような音 |
| **動き** | ダチョウ・ヒクイドリ・サギの歩行を参照。突進より「観察して、止まって、首を傾げる」 |
| **質感** | 濡れる。泥がつく。羽毛が雨で束になる。生き物は必ず「汚れて」いる |

## 7. BGM 設計

**方針**: 音楽で盛り上げない。**環境音が主役、音楽は床。**

| 区間 | 内容 | 音量（対ナレーション） |
|---|---|---|
| 00:00–00:08 | 無音に近い。40Hz 付近のサブベースのドローンのみ | −26dB |
| 00:08–00:26 | 単音のシンセ・パッドが加わる。テンポなし | −22dB |
| 00:26–00:36 | 低いパルス（心拍に近い 60BPM）が入る。徐々に密度が増す | −18dB |
| 00:36–00:44 | パルスが止まり、弦の持続音のみに。**音数を減らして緊張を作る** | −20dB |
| 00:44.6–00:45.0 | **完全無音** | −∞ |
| 00:45–00:53 | ピアノ単音＋弦。長調でも短調でもない浮遊感。**美しく、寂しく** | −20dB |
| 00:53–00:57 | 静かに減衰 | フェードアウト |
| 00:57–01:00 | 無音 | −∞ |

**参照**: Hans Zimmer『Blue Planet II』の静かな部分 / Jóhann Jóhannsson『Arrival』/ Max Richter『On the Nature of Daylight』の抑制された部分

**ラウドネス納品基準**: 統合 **−14 LUFS**、トゥルーピーク **−1.0 dBTP**（YouTube 正規化に合わせる）

## 8. SE（環境音）設計 — 本作の生命線

> **AI映像が偽物に見える最大の原因は、映像ではなく「音の不在」である。**
> 全カットに最低3レイヤーの環境音を敷くこと。

### レイヤー構成（全編共通）

| レイヤー | 内容 |
|---|---|
| **L1: ルームトーン** | そのカットの「空間の無音」。屋外・屋内・車内で必ず差し替える |
| **L2: 環境** | 雨、風、街の遠鳴り、交通、電車、蝉、カラス |
| **L3: 近接** | 足音、衣擦れ、機材、呼吸、金属、水滴 |
| **L4: 恐竜** | **吠え声禁止。** 呼気（シューという長い音）、喉の低いゴロゴロ、爪がアスファルトを叩く音、羽毛の擦れ |
| **L5: 低周波** | 大型種の存在は「音」ではなく **20–40Hz の振動**で表現。スマホスピーカーでは聞こえないが、イヤホンでは体感される |

### 日本のリアリティを作る音（必須）

- 駅の発車メロディ（遠く・不明瞭に）
- 踏切の警報音
- 自販機のコンプレッサー音
- 室外機
- 商店街のアナウンス
- カラス（**C18 以降は意図的に消す** ＝ 置換されたことの暗示）

> **C18 以降でカラスの声を消す**のは、本作で最も高度な演出。
> 明示せずに「生態系が入れ替わった」ことだけを音で伝える。

## 9. カラーグレーディング

| 項目 | 設定 |
|---|---|
| ベース | Rec.709 / 露出は 1/3〜2/3 段アンダー |
| シャドウ | ティール（`#1A2A2E` 方向）に −8 |
| ハイライト | ごく僅かに寒色。白は白のまま残す（青被りさせすぎない） |
| 彩度 | 全体 −15〜−20%。**ただし肌色だけ保持**（肌が灰色になると死体に見える） |
| コントラスト | S カーブ強め。黒を締める（黒レベル 0 まで潰さず、8〜12 で止める） |
| グレイン | 35mm 相当・強度 3〜5%。**全カットに必ず適用**（AIのノイズレス感を消す最重要処理） |
| ハレーション | 光源の周囲に僅かな赤にじみ。強度 10% 以下 |
| ゲートウィーブ | 極僅か（0.2px）。有機的な揺れが実写感を作る |

**統一 LUT を1本作り、全カットに同一適用する。** カットごとに個別調整すると「別素材の寄せ集め」に見え、ドキュメンタリー性が壊れる。

## 10. 生成ワークフロー（実制作手順）

### Step 1 — キーフレーム生成（静止画）
Midjourney v7 / Flux 1.1 Pro などで、各カットの **1枚目のフレーム**を作る。
- `--ar 9:16` を厳守
- 人物が登場するカットは、同一人物の参照画像（キャラクター参照機能）を固定
- **1カットにつき最低8案生成 → 1案採用**（打率は1割と考える）

### Step 2 — Image-to-Video
採用したキーフレームを、Veo 3 / Kling 2.x / Runway Gen-4 などへ入力。
- **text-to-video ではなく image-to-video を使う。** 構図と質感が固定され、CG感が激減する
- カメラ指定は1カットにつき**1種類だけ**（Push In と Pan を混ぜると破綻する）
- 恐竜が写るカットは特に破綻率が高い。**生成数は他の3倍を見込む**

### Step 3 — 選別基準（ここで妥協しない）
以下が1つでもあれば**破棄**。
- 手指の破綻
- 歩行時に足が地面を滑る（接地感の欠如）
- 顔が途中で別人になる
- 恐竜の尾が地面を貫通する／影が落ちていない
- カメラが物理的にありえない動きをする

### Step 4 — 整音
- 全カットに §8 のレイヤーを敷く
- ナレーションは −3dB でコンプ、200Hz ローカット、3kHz を +2dB（明瞭度）
- ナレーションが入る区間は BGM を **−6dB ダッキング**

### Step 5 — グレーディング＋グレイン
DaVinci Resolve で統一 LUT → グレイン → 最終書き出し。

### Step 6 — 編集リズム
- **カットは動きの途中で割る**（動き出しでも止まった後でもない）
- 音は映像より **2〜4フレーム先行**させる（J カット）＝ プロの編集に見える
- 3秒を超えるカットは C01 と C17 の2つだけ。それ以外は必ず2秒台に収める

## 12. 制作上の遵守事項（重要）

本作はフォトリアルな「ドキュメンタリー風」映像であるため、切り抜き転載時に誤認される可能性を最小化する。

| 項目 | 対応 |
|---|---|
| 実在の放送局・新聞社 | **ロゴ・社名・番組名を一切映さない。** 必要なら架空名を使用 |

## 付録 A. 科学的根拠メモ（説明文・固定コメント用の素材）

| 描写 | 根拠 |
|---|---|
| 大型種が数日で死ぬ | 中生代の生物は現代の細菌叢・真菌（特に *Aspergillus* 等の日和見感染）に対する獲得免疫を持たない。また消化を担う腸内共生菌が再現されない限り、摂食しても栄養を得られない |
| 植物食恐竜が餓死する | 現代の草原を支配するイネ科植物はプラントオパール（シリカ）を多く含み、これに適応した歯（高歯冠）を持たない種は摂食効率が著しく低い |
| 熱で弱る | 大型獣脚類は体積比表面積が小さく放熱が困難。日本の夏（高温多湿）は蒸散冷却も効かず、都市のヒートアイランドが追い打ちをかける |
